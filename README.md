# AudioToText Pro 🎙️

### 隐私优先，极速转录。您的下一代 Android 语音助手。

---

## 🌟 核心愿景 (Vision)
**AudioToText Pro** 完美融合了 OpenAI 的 **Whisper** 语音识别技术与灵活的 **离线/在线双模式**。我们致力于解决两大痛点：
1.  ☁️ **隐私担忧：** 拒绝将敏感会议记录上传至不可控的云端。
2.  📶 **网络依赖：** 在无网环境下也能获得高精度的语音转文字体验。

---

## 🔥 为什么选择我们？ (Why Us)

### 1. 🛡️ 隐私为先的设计 (Privacy-by-Design)
* **离线模式：** 所有数据处理均在本地 Android 设备上完成，数据 100% 私有。
* **在线模式：** 采用“零留存”策略，处理完即刻销毁，安全无忧。

### 2. ⚡️ 双模引擎 (Dual Modes)
* **本地极速版：** 基于 **whisper.cpp** 优化，无需联网，随时随地转录。
* **云端精准版：** 调用高性能云端模型，处理复杂多语言场景。

### 3. 🎛️ 灵活的模型控制
不同于竞品，我们把选择权交给您。
* **Tiny/Base 模型：** 适合旧手机，速度飞快。
* **Small/Medium 模型：** 适合高端机型，识别率媲美人工。

## 🛠️ 技术规格
* **支持格式：** MP3, WAV, M4A
* **导出格式：** TXT (纯文本), SRT (字幕文件)
* **核心技术：** Android Native, C++, Whisper.cpp, Quantized Models
